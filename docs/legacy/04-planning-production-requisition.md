# Legacy behavior 04 — Menu plan, Prep, Production, Requisition
Line numbers: `legacy/app.html`. Core math is in 02-costing-engine.md §7–8.

## 1. Data model reality (the spec's MenuPlan/MenuPlanItem does NOT exist in legacy)
- **`MENU_PLAN`** (const, line 1045; `MENU_DAYS` 1044): `[{menu:"ARABIC - SENIOR", days:[SATURDAY…FRIDAY], rows:[{m:"BREAKFAST", d:{SATURDAY:{n:"dish text", c:"MNU-0001", k:"item"|"card"}, …}}]}]`. 8 menus, 148 rows, 1001 cells (710 `item`, 290 `card`, 1 no code; 23 days absent — FILIPINO LABOUR has 6 days). Week starts Saturday. Row labels repeat across menus (BREAKFAST ×8) so a label cannot be a key. `n`=text as written, `c`=matched code, `k`: `item` → ingredient-library portion item (MNU-xxxx, all resolve to Ingredient) / `card` → recipe card code (all resolve to Recipe). Menus scoped to brand `bssem` only (`MENU_BRAND` 1040; `menusVisible()` = `S.activeBrand==='bssem'` 1043; 'plan' nav hidden for other brands 1567; menu builder only when `prodBrand==='bssem'` 2504). Prep/menuPax are not gated in legacy (D-06/D-07: now brand-scoped).
- **`S.menuPax[YYYY-MM][DD]["LOC|menuIndex"] = people`** (`paxStore` 2215, `paxKey` 2219, `setMenuPax` 2221): location prefix empty when no site selected (`"|3"`); value rounded, clamped ≥0, 0 deletes key; `menuPax` reads exactly one key (no summing across sites). Keyed by array index (breaks if menus reorder → new model uses stable `menuId`; `Menu.legacyIndex` translates old keys on restore).
- **`S.production[YYYY-MM][DD]["LOC|CODE" or "CODE"] = portions`** (`pStore` 2060, `setProd` 2072): plain `CODE` = unassigned/legacy bucket; rounded, ≥0, 0 deletes. Only a count is stored; cost read live from card (price changes reprice history). `pMonth`='YYYY-MM', `pDay`='01'..'31'; view globals `prodMonth, prodDay (default today), prodView, prodBrand='*', prodLoc='*'` (2051).
- **Locations:** `brand.locs` (strings, no ids); `pLocs()` (2057) = brand's locs, or union across brands when `prodBrand==='*'`. No add/edit UI for locs in legacy; only SSEM has them. **New (D-52):** the GM can add/rename/remove sites per brand in Brand settings (`brand.locations`); rename cascades to stored pax/production rows.
- **New model (D-05):** `Menu/MenuRow/MenuCell/MenuPax/ProductionEntry` — see schema.md. Basic editor (GM + Cost Controller, `menu.edit`): add/rename/deactivate menus, edit rows/days/cells (dish text + kind + code), version check.

## 2. Menu → card resolution (`menuPreview` 2205)
If `cell.k==='card'` use `cell.c`; else (or no code) `planFindCard(cell.n)` (02 §8). Lookup in recipes by uppercase code; none → "miss". `item` cells without a fuzzy card match never produce production/requisition. `_pcCache` invalidates when recipe count changes.

## 3. Prep (`vPrep` 1758, `prepDemand` 1738)
Selectors: site (`prodLoc`; "All sites" sets `''` — **D-20: all-sites = sum of every site + unassigned bucket on both Prep and Production**), weekday `prepDay` (default weekday of pMonth/pDay via `pWeekday` 2197 = `MENU_DAYS[(getDay()+1)%7]`). Menu table lists every MENU_PLAN row with pax input (pax stored against the Production date; dishes come from the Prep weekday). `prepDemand`: for each menu with pax>0 → `menuPreview(mi,wd)`; for each hit dish `dishes[code].pax += pax`, `reqExpand(h.r, pax, acc, 0)`; misses `missing[name]+=pax`; rows = `Object.values(acc)` sorted cost desc; `people` = Σ pax. KPIs: People, Dishes to cook, Raw materials, Food cost. Dishes table (code, name, menus, portions) sorted by pax desc; red note lists first 6 unmatched menu lines; raw-material table: code, name, uom, qty (2dp), "Wanted by" (first 3 dishes + "+N"), cost. `setMenuPax` → `guard('recipe.edit')`, save, render (D-32: `recipe.edit`). Print `prepPrint` (1893)/`prepDoc` (1863): new window with page styles, "Store requisition" title, subtitle (site/All sites, weekday, people, dishes, printed timestamp), Menus table, Raw materials table (code, name, unit, qty 2dp, blank "Issued" column, total row = material count only), signature table (Requested by / Issued by), A4 portrait, auto `print()` after 500 ms, popup-blocked fallback downloads `store-requisition.html`; audit `Sent a requisition to the store` (site + material count) is logged even if print is cancelled. CSV `prepCsv` (1910) `store-requisition.csv`: Code, Raw material, Unit, Quantity (4dp), Wanted by (names joined " | "), Cost (4dp); no BOM.

## 4. Production (`vProd` 2439)
`pQty(day,code,loc)` (2063): single-site key if loc defined and not `'*'`; else plain `code` bucket + Σ over `pLocs()` of `loc|code` (legacy caveat: sites not in current `pLocs()` ignored; `''` sentinel bug fixed by D-20). `pCards()` (2068): recipes with `type!=='sub'` filtered by `prodBrand`. `pSection(r)` maps `r.cat` (exact trimmed) to `SECTIONS` (2035; default `hot`): hot=Main Course, Arabic, Rice, Lentils & Pulses, Pasta, Vegetables, Eggs, Soup, Breakfast · sal=Salad · swt=Dessert, Fruit · bak=Bread, Bakary, Bakery, Cereal · bev=Beverage, Dairy & Spreads (each has an Arabic label; `db/seed-data/sections.json`). `pCost(r)=cost(r).food`. `pDayTotals`: per card with q>0, `v=q*pCost`; per-section totals, grand total, portions. Day UI: portion inputs per section (name-sorted) with site select, section subtotals, KPIs (day cost, portions, sections cooking of 5), `prodDrawSummary(day)` consolidated raw materials sorted by qty desc. Month view: per-day portions and per-section cost + MONTH row; month average = `gm/nd` (calendar days, not days with data); changing month resets day to today's day-of-month (can exceed month length — fix: clamp).
**menuBuilder / `applyMenuDay`** (2240, SSEM + Daily view): `menuDemand` (2227) sums pax per card across menus (`tot[code].q += pax`), misses reported; `applyMenuDay` needs `recipe.edit`, aborts without pax, **overwrites** `S.production[month][day][pKey(loc,code)]` for demanded codes only (never clears others), audit `Turned the menus into production` (weekday, date, site, people, menu count, dishes, first 10 unmatched; legacy stored HTML-escaped text — new: store plain text).

## 5. Requisition (`reqForDay` 2108, `vReq` 2118)
For each `pCards()` recipe with `pQty>0`: `per` = expansion of that recipe alone, `all` accumulated; `bySec[section]={r,p,per}`. vReq: KPIs (materials to draw, value, dishes cooking, sections), consolidated table sorted by cost desc (material+code, UOM, total to issue, value, "Used by" parent recipe + qty when >1), per-section blocks with per-recipe tables; current `pDay` and `prodLoc` only. `from` records qty per immediate parent (sub quantities are in sub units – mixed units in "Used by": known quirk).
Exports: `reqCsv` (2159) `requisition-YYYY-MM-DD.csv` (date/site header, CONSOLIDATED: Code, Raw material, UOM, Issue 1dp, Value 2dp; BY SECTION AND RECIPE: Brand, Section, Recipe, Portions, Code, Raw material, UOM, Draw 1dp). `prodCsv` (2548) **throws** (`sites` undefined) — implement intended: `production-YYYY-MM.csv` columns Month, Day, Section, Dish, Code, Portions, Cost/portion, Cost per site/card + DAY TOTAL row (D-19). `planCsv` (2023) `menu-<name>.csv`: per row dish names by day, a "cost" row (value 4dp or src text "no price"/"not matched"/"card missing"/"item missing"), TOTAL/PAX per day, WEEK TOTAL; first column = family.
Production sheets: `prodPrintMenu` (2417), `prodPrint` (2399), `prodDoc` (2370): modal lets user pick each non-empty section, "Store requisition", or "Everything"; standalone HTML via Blob URL, `print()` after 600 ms, fallback download `production-YYYY-MM-DD-<kind>.html`. Section sheet (`prodSheetSection` 2340): header brand/site/date/weekday; table Dish(+code) | Cook (portions) | Raw material to draw (name + qty 0dp + lowercase uom, "Each" blank) | Done tick; footer Prepared by / Checked by / Time; dishes name-sorted with per-dish expansion. Store sheet (`prodSheetStore` 2358): Raw material | Issue (qty 0dp+uom) | For (recipes) | Issued; footer Issued by / Received by / Time; name-sorted. "all" = sections then store with page breaks.

## 6. Audit in this area
Audited: `Turned the menus into production`, `Priced a menu item from the menu plan`, `Sent a requisition to the store`. Not audited in legacy: `setProd`, `setMenuPax`, CSV exports, `prodPrint` (keep as is; menu editing is audited as `Menu edited`).

## 7. Known quirks (see 09-known-bugs.md for decisions)
Site sentinel `''` vs `'*'`; pax unsited bucket `|mi` not summed with sited; pax keyed by index; month input day overflow; `applyMenuDay` doesn't clear stale codes; item-kind cells dropped from production; Prep print audits even on cancel.
