## 1. Dashboard (`vDash` 2614) — inputs: all recipes (legacy: all brands); `t=num(settings.target)` default .30
- Menu Items = count `type==='menu'` (sub-line "N sub-recipes"). Average Food Cost = **unweighted** mean of `fcPct` over menus with `sp>0` (null → "-"; green if ≤ t else red). Over Target = count priced menus with fcPct>t ("of N priced items"). Selling At A Loss = count priced menus with net<0. Locked & Approved = count of ALL recipes (menu+sub) `status==='locked'`, "of S.recipes.length cards". Ingredients = items.length, "X flagged" (truthy flag), "Y unpriced" (price==null).
- Table: top 25 menus by fcPct desc (nulls last): Code, Recipe(+category), Brand pill, St (lock icon/D), Food Cost, Total Cost, Sales Price ("not priced" if none), FC% pill (`fcClass`) with bar width `min(100, p/(2t)*100)` (green ≤t, warn ≤1.25t, bad above), Net Profit (red if <0), Net %, Status (`c.err` pill or OK), Open button. "+ New Recipe Card" has `data-perm recipe.create`.
- Performance by brand (hidden if the only group is "no brand"): menu count, Avg Food Cost (mean of `food` over ALL its menus), Avg FC% (priced), Over target, Avg Net Profit and Avg Net % (priced).
- Sub-recipe table first 20: batch cost, batch yield (`bOut bUom`), cost per unit (`unitCost`, 6dp), "Used in" = count of recipes with a line whose code equals sub code (case-sensitive).
- **New:** brand-scoped (D-07); show "N cards excluded (no selling price)" beside the average (D-30). Golden reality: 320/321 cards unpriced.
