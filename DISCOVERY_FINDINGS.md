## 2. Corrections to SOURCE_OF_TRUTH
| Spec says | Reality |
|---|---|
| MenuPlan / MenuPlanItem(recipe,date,location,pax) | No such thing. `MENU_PLAN` is a hard-coded 8-menu weekly constant (SSEM only, not in S). `S.menuPax[YYYY-MM][DD]["LOC|menuIndex"]=people` and `S.production[YYYY-MM][DD]["LOC|CODE"]=portions` are the only per-date data. |
| Recipe `yieldPct` | Two fields: line `y` (divisor, valid 0<y≤10 else 1; all 1 after migration) and line `yp` (waste % added in `_cost`, 15 on all patch cards). Card `buffer` (0.15) is fallback. |
| Line = ingredient XOR sub-recipe via FK | Line has only `code`. Resolution: `ITEM[code]` first, then `RCP[code]` if `type==='sub'`; menu-type code → error `not a sub-recipe`; unknown → `CODE NOT FOUND`. Persisted unknown codes are legal. |
| Per-user brand access | Does not exist in legacy (users have no brands; `activeBrand` is a UI workspace filter). **New requirement** from spec §10. |
| `IngredientBrand` overrides | Legacy has `item.brands[]` = visibility scope (empty = Shared). Not price overrides. |
| CostSettings names | `pkg, del, lab, ops, buffer, target, vat` as fractions; `currency`, `priceDate`. |
| Brand fields | `id(bnc,b1..b12,bssem), name, code, color, ink?, logo(base64), nameAr?, locs?[]`. |

## 3. Costing engine (lines 1362–1480) — frozen reference
`resolve → lineCost → batch → _cost`, `subUnitCost` (raw unit cost, **no buffer**; `total/(batchOut||subQty)`; cycle via `seen` set on code → `{v:0,err:'circular'}`; `batch` passes a copy of `seen` per line). `lineCost`: conv `S.conv[code]=[unit,factor]` applies only if line unit ≠ item uom AND stored unit == line unit → `q=qty/factor`; else `needConv` → cost 0. `_cost`: per-line `cost*(1+yp/100)` (fallback card buffer then settings.buffer), `food=(yielded||orig*(1+buf))/out`, charges = `price*pct`, `out=max(1,num(output)||1)`. Result object has ~30 fields (see `golden/costs.json`). `num()` = parseFloat→0 on NaN. All JS doubles → **Float, not Decimal**.
**Requisition/production use a different, simpler expansion (`reqExpand` 2093)**: no conv, no `yp`, no buffer, `y=num(y)||1` unclamped, sub match = any recipe code case-insensitive, depth ≤4 silently truncated. Preserved as a separate `domain/production` module — do not unify with costing.

## 4. Legacy bugs / inconsistencies (decision needed → DECISIONS.md D-20..)
1. `prodCsv` throws ReferenceError (`sites` undefined) — production CSV never worked.
2. `doBulkLock` throws TypeError (`trash`) after in-memory lock → never saved.
3. `bulkUnlock` skips PIN gate (moot, PIN removed).
4. `prodLoc` sentinel mismatch: Prep "All sites" = `''` vs Production `'*'`; `pQty('')` returns only unassigned bucket.
5. Pax keyed by menu array index; unsited bucket `|mi` not summed with sited.
6. Import never carries `yp`/`buffer`; export/print show `y*100` not `yp`; print "Variable buffer" label uses global buffer but amount uses real.
7. Import: same code under two brands in one file → duplicate codes; code collision moves card across brands. Editor allows duplicate/self-referencing codes (cycle only caught at cost time).
8. Seed items deleted by user reappear on next load (no tombstones); deleted RECIPE_PATCH cards tracked in `deletedCards` (undo doesn't clear it).
9. Restore of a standard backup wipes `security`; restore does not run migrations.
10. Audit details HTML-escaped at write (`setMenuPrice`, item import) then escaped again at display; audit cap 600 only via `logit`.
11. Unguarded server-side-equivalents: brand add/edit, settings percent edits, `export` perm never checked; `brands.edit` only on delete.
12. `saveItem` rebuilds the object (drops unknown fields); delete item leaves orphan `conv` key.
13. Photos/logos base64 inside S; `Signed in/out` flood audit.
14. Dashboard averages are unweighted, all brands, and "Locked" counts subs.
15. Print "Variable buffer" label vs amount mismatch; month avg divides by calendar days; day select can exceed month length.
