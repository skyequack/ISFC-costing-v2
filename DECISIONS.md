| D-56 | **Behaviours chosen while building Phases 3–6 (2026-10-09, defaults — tell me to change any).** (a) **Restore** = "bring the system to the backup" keyed by CODE: settings, brands, ingredients (+scope, conversions), cards (+lines, method, lock history), menus, headcounts, production are upserted; cards the backup lacks are **soft-deleted** (undoable), ingredients it lacks are **kept** and counted, menus it lacks are **deactivated**; the audit log and price history are never touched; images are replaced only when the backup carries them. Dry-run applies and rolls back. A circular or inconsistent backup is refused. (b) **Recipe upload** is strict where legacy was lenient (D-36): a line whose code is unknown or not available to the caller **blocks that card**, and any blocked card makes the whole part refuse to commit; a code seen twice in a part, a code that is already an ingredient, a card of a brand the caller cannot edit and a cycle across the file + stored cards are blocked; moving a card to another brand needs both brands. Locked cards are skipped, never overwritten. `Waste %` carried over by line code when the file has no such column; `Card Buffer` untouched when absent. Template demo rows that repeat the demo code are skipped (legacy imported them as cards). (c) **Active brand workspace** is a validated cookie, not localStorage. (d) **Audit**: `Created card`, `Renamed card code`, `Edited card` (one entry per user/card per 10 minutes so autosave is not noise); price/yield/photo/lock entries keep their legacy wording. (e) **Exports** are served by the API only (permission + scope + audit); Excel files are built in the browser from the row data the API returns. (f) **Production CSV** (D-19) columns: Month, Day, Site, Brand, Section, Dish, Code, Portions, Cost/portion, Cost, plus `DAY TOTAL` rows; a lone `-` is not neutralised by the CSV formula guard. (g) Spreadsheet parsing runs in the browser main thread with size/row/zip-bomb caps (worker deferred). (h) Recipe list order is by code. (i) A Prep/Production headcount typed under "All sites" is saved to the unassigned bucket and counted with every site (D-20). | 🟡 default |
